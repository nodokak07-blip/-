# Bloom Journal UI conventions

Before changing the interface, read `docs/ui-guidelines.md`.

- Refer to the operator as 「カウンセラー」 consistently in user-facing and administrator-facing text.
- Preserve the existing Bloom Journal / BEAUTY JOURNAL tone, fonts, colors and soft visual style. Reuse `--font-main`, `--font-serif-jp`, and `--font-serif-en`, including exported report images.
- Use the shared vector icons and original drop animation rather than device-dependent emoji icons.
