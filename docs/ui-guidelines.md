# Bloom Journal：表記とトーン＆マナー

2026年11月10日の利用者指示に基づく、今後の画面変更の共通方針。

- 運営者の呼称は「カウンセラー」に統一する。利用者画面、管理画面、報告・返信・案内文にも同じ呼称を使う。
- 既存のBloom JournalとBEAUTY JOURNALに合わせ、字体・色・余白・やわらかな質感を保つ。
- 本文・入力・ボタンは既存の `--font-main`、日本語見出しは `--font-serif-jp`、英字ロゴ・装飾用の数字は `--font-serif-en` を使う。新しい画面だけを別の汎用フォントにしない。
- 画像として保存する月次カードにも同じフォント設定を適用する。
- 既存のくすみローズ、クリーム、ミントを基調とし、強い原色・太い文字・過剰な装飾を増やさない。説明や数値が読みやすいコントラストは確保する。
- 端末固有の絵文字をUIアイコンに使わず、共通の線画アイコンとオリジナルのしずくを使う。
- しずくはやわらかく伸び縮みして合流する。毎日の記録は蓄積し、月次だけをカウンセラーに報告する。動きを減らす端末設定を尊重する。
- 記録のしずくは背景のしずくになじむ透明なピンクを基調に、青みがかった白い反射光を重ねる。緑の塊にしない。しずくの中に「0粒・1粒・2粒」という数え方を表示せず、外側に「今日の記録」と記録した項目数を控えめに示す。
- 習慣の選択肢は「できた／スキップ」とする。過去の記録や管理者向けの表示も「スキップ」で統一し、否定的な表現にしない。保存値のfalseと未記録は区別し、スキップも記録としてしずくに加える。達成率の実施回数には加えない。
- ローカル確認版には保存・送信を行わない動きのデモを置く。本番の記録操作と混同させず、アニメーションと実データの保存を区別する。
- しずくはカーソルを重ねたときや、スマホで触れたときに小さく揺れる。周囲の狭い範囲にも反応し、揺れは短時間で収まる。スクロールを妨げず、触れるだけで記録・保存・送信しない。キーボード操作と端末の「動きを減らす」設定にも対応する。
- 主ナビゲーションは「ホーム → 目標設定 → 記録レポート → わたしの歩み → グループ → みんなのご飯 → コラム」の順。「その他」というタブは使わない。以前の体調記録への入口を「記録レポート」に残し、以前の記録は削除しない。
- 「わたしの歩み」は選択肢を最初から表示し、コメントなしで残せる。自由コメントは下部の控えめな折りたたみ欄に置く。応援は共通の線画アイコン付きリアクションにし、スマホの絵文字を使わない。
- 「届いた応援」は自分の歩みへのリアクション、「大切な言葉」は自分の歩みに届いたコメントを自動で表示する。数やランキングを大きく強調しない。
- 公開範囲は初期状態を「自分だけ」とし、カウンセラーや承認済みグループへの共有は本人が選ぶ。保存ボタンと共有ボタンの文言を区別する。
- 「定期カウンセリングの予約」は指定のTimeRex URLへつなぎ、「新規の方は別途お問い合わせが必要です。」を添える。淡いローズの縁、光沢、やわらかな影で少し浮き上がらせ、押したときには軽く沈ませる。
- アカウント・プロフィール設定はヘッダー右上の歯車から開く。ニックネームの変更とログアウトを別の操作として示し、本名・メールの入力を求めない。
- 写真投稿の入口は「みんなのご飯」。食事の写真やひとことを気軽に残す場として案内し、手づくり・外食・おやつを区別せず、量や内容の良し悪しを評価しない。投稿頻度を求めない。レシピの蓄積は今後の別機能として扱う。

- 2026年11月11日更新：スマホの主ナビは7項目を1段の横並びにする。表示は「ホーム・目標・レポート・歩み・グループ・ご飯・コラム」と短くし、読み上げ名は正式名称を保つ。左右12pxを共通の余白にし、二重の内側余白を避ける。横並びの入力欄・選択肢・ボタンは均等幅と揃った高さを基本にする。

- スワイプは上方向へ短く軽く払う操作で受け付け、入力欄の操作・横移動・取り消しと区別する。日次記録は演出より先に保存し、しずくが画面外でも合流を見せる。月次本文はスクロール可能とし、報告は下部の専用スワイプエリアまたは明示的な報告ボタンから行う。

- 月次レポートは対象月を1行、各目標の項目名と実績を横並びにして縦の余白を抑える。目標・達成率・記録／未記録日数は省略しない。スワイプの案内には共有マークを使わず、丸みのある上向き二重矢印（ic-swipe-up）を使う。
