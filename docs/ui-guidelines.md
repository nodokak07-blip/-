# Bloom Journal：表記とトーン＆マナー

2026年11月10日の利用者指示に基づく、今後の画面変更の共通方針。

- 運営者の呼称は「カウンセラー」に統一する。利用者画面、管理画面、報告・返信・案内文にも同じ呼称を使う。
- 既存のBloom JournalとBEAUTY JOURNALに合わせ、字体・色・余白・やわらかな質感を保つ。
- 本文・入力・ボタンは既存の `--font-main`、日本語見出しは `--font-serif-jp`、英字ロゴ・装飾用の数字は `--font-serif-en` を使う。新しい画面だけを別の汎用フォントにしない。
- 画像として保存する月次カードにも同じフォント設定を適用する。
- 既存のくすみローズ、クリーム、ミントを基調とし、強い原色・太い文字・過剰な装飾を増やさない。説明や数値が読みやすいコントラストは確保する。
- 端末固有の絵文字をUIアイコンに使わず、共通の線画アイコンとオリジナルのしずくを使う。
- しずくはやわらかく伸び縮みして合流する。毎日の記録は蓄積し、月次だけをカウンセラーに報告する。動きを減らす端末設定を尊重する。
- 記録のしずくは背景のしずくになじむ透明なピンクを基調に、青みがかった白い反射光を重ねる。緑の塊にしない。しずくの中に「0粒・1粒・2粒」という数え方を表示せず、外側に「今日の記録」と記録した項目数を控えめに示す。
- 習慣の選択肢は「できた／今日はスキップ」とする。過去の記録や管理者向けの表示も「スキップ」で統一し、否定的な表現にしない。保存値のfalseと未記録は区別し、スキップも記録としてしずくに加える。達成率の実施回数には加えない。
- ローカル確認版には保存・送信を行わない動きのデモを置く。本番の記録操作と混同させず、アニメーションと実データの保存を区別する。
